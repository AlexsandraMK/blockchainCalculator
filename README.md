## Установка и запуск

1. **Настройки контракта и тестовой сети**: Чтобы настроить параметры блокчейн-контракта и тестовой сети, скопируйте файл `.env.example` в файл `.env`:

```bash
cp .env.example .env
```

В файле `.env` вы сможете настроить параметры, такие как:
  - Адрес контракта (CONTRACT_ADDRESS)
  - URL тестовой сети (INFURA_API_URL)
  - Приватный ключ кошелька (PRIVATE_KEY)

2. **Добавьте приватный ключ в файл .env**: Для работы с блокчейн-сетью вам необходимо указать приватный ключ вашего кошелька (например, MetaMask). 

3. **Установите зависимости для серверной части**: Перейдите в папку с репозиторием и выполните команду:

```bash
npm install
```

4. **Установите зависимости для клиентской части**: После этого перейдите в папку `frontend`:

```bash
cd frontend
```
 и выполните команду:

```bash
npm install
``` 

   
5. **Запустите серверную часть**: Вернитесь в папку с репозиторием (если вы все еще в папке `frontend`, выполните `cd ..`) и запустите сервер с помощью команды:
```bash
npm start
```

Сервер будет работать по адресу `http://localhost:3000`.
